Проекты

il2cpp-instrumentation-study
IL2CPP runtime instrumentation bridge. C++ / LD_PRELOAD. Signature-based method resolution, lazy class init, main-thread dispatch. 38 exported C-ABI functions. Для автоматизации закрытых Unity-клиентов и patch-resistant резолва методов без зависимости от обновлений таргета.
native-bridge-ipc
Двухуровневый IPC: AF_UNIX socket с автоматическим fallback на file-based flock. Auto-negotiated request-ID protocol. Python + C++ demo host. Надёжная связь между нативным кодом и Python-контроллером в условиях нестабильного хоста и множественных клиентов.
process-supervisor
Эскалирующий watchdog с health-probe интерфейсом, chain-based recovery, sliding-window circuit breakers, episode tracker для дуг состояний. Самовосстанавливающийся вотчдог для long-running сервисов с защитой от бесконечных рестартов.
streaming-market-analytics
End-to-end streaming-платформа. Go workspace (ingest / features / api), Python-аналитика, 21 миграция TimescaleDB, NATS JetStream, Prometheus + Grafana + Loki. Полный пайплайн для аналитики рыночных данных в реальном времени с прогнозированием и Grafana-дашбордами.
